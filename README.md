# ServiceDesk Pro — Full-Stack IT Helpdesk & Asset Management Platform

**Live Backend API**: `https://servicedesk-lrjr.onrender.com`

ServiceDesk Pro is an enterprise IT Helpdesk, SLA Governance, and Hardware Asset Lifecycle Management platform built with the MERN Stack (MongoDB, Express.js, React, Node.js), styled with a modern **calm operations editorial design system** (warm off-white `#FAF9F6`, terracotta `#B5502F`, slate blue `#3E5C76`, Google Fonts *Source Serif 4* & *Inter*).

---

## 🚀 Key Platform Features

### 1. Role-Based Access Control (RBAC) & Persona Switcher
- **5 Roles**: `admin`, `it_manager`, `technician`, `asset_manager`, `employee`.
- 1-click **Demo Persona Switcher** on Login screen for instant role testing.
- Pre-seeded Demo Accounts:
  - **Administrator**: `admin@servicedesk.com` (Password: `Admin123!`)
  - **IT Manager**: `manager@servicedesk.com` (Password: `Manager123!`)
  - **Technician**: `tech@servicedesk.com` (Password: `Tech123!`)
  - **Asset Manager**: `asset@servicedesk.com` (Password: `Asset123!`)
  - **Employee**: `employee@servicedesk.com` (Password: `Employee123!`)

### 2. Full Ticket Lifecycle Management
- Sequential autoincrement IDs (`INC-1001`, `INC-1002`).
- Public responses vs. **Internal Technician Notes** (automatically hidden from standard employee view).
- Work time logging (`WorkLog`) with technician billable hour tracking.
- State transitions (`new` -> `in_progress` -> `resolved` -> `closed` -> `reopened`).

### 3. Business-Hours SLA Engine & Cron Scanner
- Calculates SLA deadlines strictly within business operating hours (Mon–Fri 09:00 AM – 06:00 PM).
- Automatically rolls over target deadlines across weeknights and weekends.
- `node-cron` background scanner (runs every 5m) detects SLA breaches, flags `isSlaBreached: true`, auto-escalates to IT Manager, and triggers alert notifications.

### 4. Hardware Asset & Vendor Lifecycle
- Autogenerated asset tags (`AST-4001`) and serial number validation.
- Lifecycle state transitions (`in_stock` -> `assigned` -> `in_repair` -> `retired`).
- 30-day warranty expiration alert pills and audit trail history.

### 5. AI Triage Assistant & Fallback Engine
- Intelligent ticket classification (suggests category, priority level, and 1-2 sentence probable root cause breakdown).
- Graceful degradation: Built-in local semantic/heuristic classifier if remote AI API key is unconfigured or times out.
- Knowledge-Base Article recommendation panel for technicians.

### 6. Live MongoDB Analytics & Server CSV/PDF Exports
- Recharts visualizations styled with editorial color palettes.
- All metrics derived dynamically from MongoDB (**Zero hardcoded stats**).
- Server-side streaming CSV exports (`/api/reports/tickets/csv`, `/api/reports/assets/csv`) and executive PDF report generator (`/api/reports/pdf`).

### 7. Notification Center & Audit Log History
- In-app notification center with live unread badge counter in header navigation.
- Immutable system audit log viewer (`/admin/audit-logs`) tracking ticket status transitions and hardware lifecycle events.

## 🛠️ Project Setup & Installation

### Prerequisites
- Node.js (v18+)
- MongoDB (Running locally at `mongodb://127.0.0.1:27017/servicedesk_pro` or MongoDB Atlas connection string)

### 1. Server Setup (`/server`)
```bash
cd server
npm install
npm start
```
*On initial startup, MongoDB connection automatically seeds demo users, Acme departments, SLA policies, organic tickets, hardware assets, and Knowledge Base articles.*

### 2. Client Setup (`/client`)
```bash
cd client
npm install
npm run dev
```
*Access frontend UI at `http://localhost:5173`.*

## 🧪 Running Automated Test Suites

From the `/server` directory, execute targeted CLI test suites:
- **SLA Business Hours Engine**: `node src/utils/testSlaEngine.js`

npm run build
